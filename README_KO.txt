NIRC 5000m TT 관리 앱 v1

1. 현재 포함 데이터
- 2026-07-08 결과표 27명
- 2026-08-05 결과표 25명

2. 기능
- 월별 결과 조회
- 개인별 기록 변화 그래프
- PB 자동 표시
- 전월 대비 향상/하락
- km당 평균 페이스 / 400m 평균 자동 계산
- CSV 내보내기
- CSV 파일 또는 표 붙여넣기로 새 월 기록 추가
- 브라우저 로컬 저장
- PWA 기본 구성

3. 실행
- 가장 쉬운 방법: GitHub Pages 등에 폴더 전체 업로드 후 index.html 실행
- PC 로컬에서는 Python이 있으면 이 폴더에서:
  python -m http.server 8000
  이후 http://localhost:8000 접속

4. 9월 기록 입력 형식
이름,훈련조,5000m기록,VDOT
홍길동,1조,20:15,49.0
